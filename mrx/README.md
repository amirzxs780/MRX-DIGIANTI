# ربات تلگرامی (پاسخ خودکار + مدیریت گروه + اطلاع‌رسانی)

## مراحل راه‌اندازی

### ۱. ساخت ربات و گرفتن توکن
1. توی تلگرام به [@BotFather](https://t.me/BotFather) پیام بده.
2. دستور `/newbot` رو بزن و اسم و یوزرنیم دلخواه رو وارد کن.
3. توکنی که میده رو کپی کن (چیزی شبیه `123456:ABC-DEF...`).

### ۲. گرفتن آیدی عددی خودت (برای ادمین بودن)
به ربات [@userinfobot](https://t.me/userinfobot) پیام بده تا آیدی عددیت رو بهت بده.
این عدد رو توی `config.py` داخل لیست `ADMIN_IDS` بذار.

### ۳. نصب پیش‌نیازها
```bash
pip install -r requirements.txt
```

### ۴. تنظیم توکن
```bash
export BOT_TOKEN="توکنی که از BotFather گرفتی"
```
(روی ویندوز: `set BOT_TOKEN=...`)

### ۵. اجرا
```bash
python bot.py
```

### ۶. اضافه کردن ربات به گروه
- ربات رو به گروه اضافه کن.
- توی تنظیمات گروه، ربات رو **ادمین** کن (برای اینکه بتونه پیام‌ها رو حذف کنه).
- برای اینکه پیام خوش‌آمدگویی کار کنه، باید هنگام ساخت ربات نزد BotFather دسترسی
  "Group Privacy" رو بررسی/غیرفعال کنی (`/setprivacy` -> Disable) تا ربات همه‌ی پیام‌ها رو ببینه.

## قابلیت‌ها

| قابلیت | توضیح |
|---|---|
| سوییچ کلی ربات | همه‌چیز پیش‌فرض **خاموشه**. با نوشتن «ربات روشن» (یا دکمه‌ی بالای `/menu`) فعالش کن؛ تا وقتی روشن نکنی، ربات به هیچ‌چیزی جز دستورات صریح (`/command`) واکنش نشون نمی‌ده |
| ذخیره‌سازی دائمی | همه‌ی تنظیمات/لیست‌ها/آمار توی فایل `bot_state.json` ذخیره می‌شه؛ با ری‌استارت شدن ربات از بین نمی‌ره (نکته‌ی Railway رو پایین‌تر بخون) |
| پنل کامل (`/menu`) | یه لیست دکمه‌ای برای همه‌چیز: سوییچ کلی، خوش‌آمدگویی، پاسخ کلیدواژه‌ای، هرکدوم از ۵ تا ضداسپم، ثبت آمار، سیستم دوست/دشمن، حالت AI، حد اخطار، مدت میوت — هرکدوم با یه لمس روشن/خاموش/چرخش می‌کنه، و دکمه‌ی «❌ بستن» هم داره |
| پاسخ خودکار | کلیدواژه‌ها توی `AUTO_REPLIES`؛ جدا از AI با `/menu` روشن/خاموش می‌شه |
| خوش‌آمدگویی | متن پیام رو توی `WELCOME_MESSAGE` تغییر بده؛ با `/menu` روشن/خاموشه |
| ضداسپم پیشرفته | فیلتر کلمات/لینک، فلود متن، کاپس‌لاک، فلود استیکر/گیف، فوروارد از کانال، لینک از اعضای تازه‌وارد — هرکدوم جدا از `/menu` قابل روشن/خاموش کردنه |
| قفل کامل استیکر/گیف | برخلاف «ضد فلود استیکر/گیف» که فقط جلوی اسپم پشت‌سرهم رو می‌گیره، این حتی یه استیکر/گیف تنها رو هم حذف می‌کنه؛ با `/menu` روشن/خاموشه |
| بن/آن‌بن | `/ban <آیدی یا ریپلای> [دلیل]` و `/unban <آیدی>` |
| ارتقا/عزل ادمین | `/promote` و `/demote` (آیدی یا ریپلای) - کاربر رو ادمین تلگرامی گروه می‌کنه/از ادمینی درش میاره؛ دسترسی جدا (`manage_admins`) داره چون خطرناکه |
| پاک‌سازی پیام‌ها | `/purge` - ریپلای رو یه پیام بزن، همه‌ی پیام‌های بین اون تا همین لحظه پاک می‌شه |
| تایید عضو جدید (ضد ربات اسپمی) | با `/menu` روشن کن؛ عضو جدید تا دکمه‌ی «تایید می‌کنم ربات نیستم» رو نزنه نمی‌تونه پیام بده، و اگه تا `CAPTCHA_TIMEOUT_MINUTES` دقیقه تایید نکنه خودکار اخراج می‌شه |
| هشدار + میوت تصاعدی | حد اخطار و مدت میوت پایه رو با دکمه‌های `/menu` تنظیم کن؛ هر بار یه نفر دوباره میوت بشه مدتش خودکار دوبرابر قبلیه (تا سقف `MAX_MUTE_MINUTES`)؛ برای اخطار/میوت/آن‌میوت دستی: `/warn`, `/mute`, `/unmute`, `/resetwarnings`, `/warnings`, `/muted` (لیست میوت‌شده‌های الان) |
| بلاک‌لیست دستی | `/blacklist_add` و `/blacklist_remove` (ریپلای یا آیدی) - پیام‌های این افراد همیشه حذف می‌شه |
| آمار فعالیت | با `/menu` روشن/خاموشه؛ `/stats` (تعداد پیام، میانگین طول، تعداد مدیا)، `/top` فعال‌ترین‌ها، `/groupstats` فعال‌ترین ساعت/روز گروه، `/groups` نمای کلی همه‌ی گروه‌هایی که ربات توشونه |
| چت هوشمند (AI) | با `/menu` بین ۴ حالت می‌چرخه: خاموش / همه / فقط غیرادمین‌ها / فقط ادمین‌ها |
| دوست/دشمن (ترمیناتور) | با ریپلای یا `/addenemy`, `/addfriend`, `/removeenemy`, `/removefriend` (با آیدی) کاربرو علامت بزن؛ `/enemies` و `/friends` لیستشون رو نشون می‌ده؛ کلماتی که با ریپلای زدنشون دشمن/دوست می‌سازن رو با `/addenemyword`, `/addfriendword` (و remove) خودت اضافه/حذف کن؛ `/enemywords`, `/friendwords` لیستشون رو نشون می‌ده؛ ترمیناتور فقط رو همین سیستمه، جدا از AI/اسپم، و با `/menu` روشن/خاموشه |
| اطلاع‌رسانی | دستور `/notify متن پیام` (فقط برای ادمین‌های داخل `ADMIN_IDS`) به تمام چت‌هایی که ربات توشونه پیام می‌فرسته |

## اجرای ۲۴ ساعته روی Railway (رایگان)

⚠️ **نکته‌ی مهم درباره‌ی ذخیره‌سازی:** این ربات تنظیمات/لیست‌ها/آمار رو توی فایل `bot_state.json` کنار خودش ذخیره می‌کنه تا با ری‌استارت شدن از بین نره. اما فضای ذخیره‌سازی Railway به‌صورت پیش‌فرض **موقتیه** — یعنی با هر بار ری‌دیپلوی (مثلاً بعد از push جدید به گیت‌هاب)، این فایل ممکنه پاک بشه. برای دائمی کردنش:
1. توی پروژه‌ی Railway برو به تب **Volumes**
2. یه Volume جدید بساز و Mount Path رو بذار روی `/app` (یا هرجایی که کد توشه)
3. حالا فایل `bot_state.json` روی همون Volume دائمی می‌مونه، حتی بعد از ری‌دیپلوی

اگه این مرحله رو انجام ندی، ربات همچنان کار می‌کنه، فقط با هر ری‌دیپلوی تنظیماتش به حالت پیش‌فرض (همه‌چیز خاموش) برمی‌گرده.

[Railway](https://railway.app) یه سرویس هاست ساده‌ست که با گیت‌هاب وصل می‌شه و کد رو خودکار اجرا می‌کنه.

### مرحله ۱: آپلود پروژه روی گیت‌هاب
1. یه ریپازیتوری جدید (می‌تونه Private باشه) توی [github.com](https://github.com) بساز.
2. فایل‌های این پروژه (`bot.py`, `config.py`, `requirements.txt`, `Procfile`) رو توش آپلود کن.
   > **نکته امنیتی:** توکن ربات رو هیچ‌وقت داخل کد یا `config.py` ننویس؛ چون داخل مرحله بعد به‌صورت متغیر محیطی جدا ستش می‌کنیم.

### مرحله ۲: ساخت پروژه در Railway
1. با اکانت گیت‌هابت وارد [railway.app](https://railway.app) شو.
2. **New Project → Deploy from GitHub repo** رو بزن و ریپازیتوری‌ای که ساختی رو انتخاب کن.
3. Railway خودش تشخیص می‌ده پایتونیه و `requirements.txt` رو نصب می‌کنه.

### مرحله ۳: تنظیم متغیر محیطی توکن
1. توی صفحه‌ی پروژه، برو به تب **Variables**.
2. یه متغیر جدید بساز: `BOT_TOKEN` = توکنی که از BotFather گرفتی.

### مرحله ۴: تنظیم نوع سرویس روی Worker (نه Web)
چون این ربات یک وب‌سرور نیست (فقط polling می‌کنه)، لازم نیست پورتی باز بشه:
1. توی تب **Settings**، بخش **Deploy**، مطمئن شو که Railway از `Procfile` استفاده می‌کنه (پیش‌فرض همینه).
2. نیازی به فعال کردن "Generate Domain" نیست؛ اون فقط برای سرویس‌های وب لازمه.

### مرحله ۵: دیپلوی
با هر بار push کردن به گیت‌هاب، Railway خودکار ری‌دیپلوی می‌کنه. از تب **Deployments** می‌تونی لاگ‌های زنده‌ی ربات رو ببینی و مطمئن شی که در حال اجراست.

> پلن رایگان Railway محدودیت ساعت مصرف ماهانه داره (معمولاً چند صد ساعت رایگان). برای یک ربات ساده‌ی شخصی معمولاً کافیه، ولی اگه تمومش کردی باید پلن پولی (چند دلار در ماه) رو فعال کنی.

## فعال کردن پاسخ هوشمند با هوش مصنوعی (Gemini)

با این تنظیم، ربات به هر پیامی که با کلیدواژه‌های `AUTO_REPLIES` مچ نشه، با هوش مصنوعی جواب می‌ده.

### مرحله ۱: گرفتن کلید API
1. برو به [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
2. با اکانت گوگلت وارد شو و یه کلید API بساز (رایگانه، با محدودیت تعداد درخواست در روز)
3. کلید رو کپی کن

### مرحله ۲: نصب کتابخونه‌ی جدید
```powershell
pip install -r requirements.txt
```

### مرحله ۳: تنظیم کلید
```powershell
$env:GEMINI_API_KEY="کلیدی که گرفتی"
```

### مرحله ۴: اجرا
```powershell
python bot.py
```

حالا هر پیامی که کلیدواژه‌ی خاصی توش نباشه، با جمینای جواب داده می‌شه. شخصیت و لحن ربات رو می‌تونی توی `config.py` با متغیر `AI_SYSTEM_INSTRUCTION` تغییر بدی.

برای دیپلوی روی Railway، یادت نره متغیر `GEMINI_API_KEY` رو هم مثل `BOT_TOKEN` توی تب Variables اضافه کنی.

## دسترسی چند ادمین (پنل مدیریت)

می‌تونی چند ادمین با دسترسی‌های متفاوت تعریف کنی. توی `config.py`:

```python
ADMIN_IDS = [
    7286496010,      # خودت
    111111111,       # ادمین دوم (آیدیش رو از @userinfobot بگیر)
]

ADMIN_PERMISSIONS = {
    7286496010: {"menu", "notify", "manage_relationships", "manage_blacklist"},  # دسترسی کامل
    111111111: {"manage_relationships"},  # فقط دوست/دشمن کردن
}
```

اگه آیدی یه ادمین توی `ADMIN_PERMISSIONS` نباشه، پیش‌فرض دسترسی کامل داره. دسترسی‌های ممکن:
- `menu` — استفاده از `/menu`
- `notify` — استفاده از `/notify`
- `manage_relationships` — دوست/دشمن کردن و روشن/خاموش کردن ترمیناتور
- `manage_blacklist` — بلاک‌لیست

**نکته‌ی پیش‌فرض:** «پاسخ هوش مصنوعی» و «سیستم دوست/دشمن» به‌صورت پیش‌فرض **خاموش** هستن؛ هر ادمینی که دسترسی `menu` داره می‌تونه با `/menu` روشنشون کنه. توی همون منو یه دکمه‌ی «❌ بستن» هم هست که پیام منو رو کامل حذف می‌کنه.

## پنل چندلایه (سوپر پنل) و قابلیت‌های جدید

`/menu` حالا یه پنل دسته‌بندی‌شده‌ست: اول یه لیست از بخش‌ها می‌بینی (🤖 هسته، 👋 ورود، 💬 پاسخ‌دهی، 🔒 قفل‌ها، 🛡️ ضداسپم، ⚠️ اخطار/میوت، ⚔️ دوست/دشمن)، روی هرکدوم بزنی زیرمنوی همون بخش باز می‌شه، با دکمه‌ی «🔙 بازگشت» و «❌ بستن».

**قفل‌های جدید (بخش 🔒 قفل‌ها):** تگ (@یوزرنیم)، هشتگ (#)، اشتراک مخاطب، موقعیت مکانی، رسانه (عکس/ویدیو/فایل)، قفل کامل استیکر/گیف، ربات (اخراج خودکار هر ربات دیگه)، ویرایش پیام (حذف پیام‌های ادیت‌شده)، بستن کل گروه (فقط ادمین حرف بزنه).

**مدیریت کاربر:**
- `/ban`, `/unban`, `/banlist`, `/clearbanlist`
- `/warn`, `/unwarn`, `/resetwarnings`
- `/mute`, `/unmute`, یا بنویس «سکوت ۲۶» با ریپلای برای ۲۶ دقیقه میوت
- `/addvip`, `/removevip`, `/viplist` — کاربر ویژه از همه‌ی قفل‌ها/ضداسپم مستثناست، مثل ادمین

**ادمین‌ها:** `/promote <آیدی> [لقب دلخواه]`, `/demote`

**گروه:** `/purge` (پاک‌سازی)، `/newlink` (تازه‌سازی لینک عضویت)

**تایید عضو جدید (ضد ربات اسپمی):** با `/menu` فعالش کن — عضو جدید تا دکمه نزنه نمی‌تونه حرف بزنه، وگرنه اخراج می‌شه.

**سرگرمی:** `/joke`, `/fortune` (با هوش مصنوعی تولید می‌شن، نیاز به سرویس جدا ندارن)

### چیزهایی که عمداً اضافه نکردم

- **دستور «لود» (به‌روزرسانی از راه دور):** به ربات اجازه نمی‌دم کد رو از یه لینک دانلود و اجرا کنه — این یه حفره‌ی امنیتی جدیه (هرکی به اون لینک دسترسی داشته باشه می‌تونه کد دلخواهش رو روی سرورت اجرا کنه). برای آپدیت، همیشه فایل‌ها رو دستی جایگزین کن.
- **ارز، بورس، اخبار ایران:** این‌ها نیاز به یه سرویس داده‌ی زنده و جدا (و معمولاً پولی) دارن که فعلاً وصل نیست. اگه یه API کلید براشون گرفتی، بگو تا اضافه‌شون کنم.
- **پاکسازی خودکار اکانت‌های Delete Account:** تلگرام راه ساده‌ای برای اسکن کل اعضای گروه نمی‌ده (فقط از طریق رویدادهای ورود/خروج می‌شه ردشون کرد)، پس این به‌صورت خودکار و کامل قابل پیاده‌سازی نیست.
- **سیستم امتیاز مثبت/منفی و قفل Inline/Limit/سخت‌گیرانه:** یا قبلاً با قابلیت‌های دیگه پوشش داده شده (مثل آمار و اخطار)، یا آنقدر مبهم/خاص بودن که ترجیح دادم به‌جای حدس زدن، فعلاً نسازمشون — بگو دقیق چی مدنظرته تا اضافه کنم.

## نکات مهم
- برای اینکه قابلیت‌های میوت/بن/تایید عضو جدید کار کنن، وقتی ربات رو ادمین گروه می‌کنی، دسترسی «Restrict Members» (محدود کردن اعضا) و «Ban Users» (بن کردن) رو براش فعال کن. برای `/promote` و `/demote` هم دسترسی «Add New Admins» لازمه. برای `/purge` دسترسی «Delete Messages». برای `/newlink` دسترسی «Invite Users via Link».
- این نسخه از حافظه‌ی داخلی (in-memory) برای لیست چت‌ها، آمار، اخطارها و لیست دوست/دشمن استفاده می‌کنه؛ یعنی با ری‌استارت شدن ربات، همه‌شون پاک می‌شن. برای production بهتره این‌ها رو توی یک فایل یا دیتابیس (مثلاً SQLite) ذخیره کنی.
- برای هاست کردن ۲۴ ساعته، می‌تونی از سرویس‌هایی مثل یک VPS ساده، Railway، یا PythonAnywhere استفاده کنی.
- اگه می‌خوای ربات به‌جای polling از webhook استفاده کنه (برای سرورهای production)، بگو تا اون بخش رو هم اضافه کنم.
